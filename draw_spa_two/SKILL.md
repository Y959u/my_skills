# draw_spa_two

使用 scripts/draw_spa_two.py 根据真实数据绘图，不使用 AI 图片生成。用户后续明确指定的样式优先。

## 输入与运行

- 接收 CSV 路径；第一列为样本编号，其余列为波长，表头形如 `B_423.55`，每行一个样本。波长以 nm 为单位，反射率保留原始比例值。
- 若用户只给文件夹，先查找其中的 CSV；多个候选且无法从上下文确定时询问选择。不要硬编码历史数据路径。
- 使用装有 numpy、matplotlib 的 Python 运行：

```text
python <skill目录>/scripts/draw_spa_two.py <CSV路径>
```

- 可选参数：`--output-dir`、`--title`、`--seed`、`--font`。默认输出至 CSV 所在文件夹。脚本会更新同名的两张输出，不改原 CSV。
- 如果缺少依赖，寻找已有可用 Python 环境；字体需支持中文，可用 `--font` 指定字体文件。
- 非此结构的数据先核实排列方式并适配；不要静默丢弃非数值、缺失值或样本。不要插值、平滑、归一化、求均值或外推。

## 固定样式

- 所有样本画在同一张图中，一行一条曲线。
- 四色：蓝 `#2878B5`、绿 `#2A9D65`、橙 `#E68A2E`、紫 `#8B5BB5`。随机种子 42；两张图中同一样本的颜色一致。颜色没有分类含义，不添加分类图例。
- 纯白背景，无网格；隐藏上、右边框；曲线宽 0.75、透明度 0.7。
- 横坐标“波长（nm）”，默认右端 1020，显示 1000 刻度。如果输入超过 1020，自动扩展范围以保留全部数据。
- 纵坐标“反射率”，隐藏零点文字 `0.0`，保留其他刻度。反射率无量纲，不转换为百分比。
- 10 × 6 英寸，300 dpi PNG。标题默认“所有样本的光谱反射率”。
- 输出 `all_samples_reflectance_with_title.png` 和 `all_samples_reflectance_without_title.png`。

## 检查与交付

运行后核对样本数、波段数及输出路径，查看两张图片，确认全部曲线、中文、1000 刻度正常，零点文字和网格已隐藏。最终提供两张成品的文件链接或预览。
